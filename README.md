## 1단계 — GitHub Pages 배포 (5분, 무료)

1. GitHub(https://github.com) 가입/로그인
2. 우측 상단 **+** → **New repository** → 이름 예: `mandeok-art` → Public → Create
3. **uploading an existing file** 클릭 → `index.html` 드래그 → Commit changes
4. **Settings → Pages** → Branch: `main`, 폴더: `/ (root)` → **Save**
5. 1~2분 뒤 `https://내아이디.github.io/mandeok-art/` 접속 가능

> 이 주소가 학생 접속 링크이자 QR 코드에 담기는 주소입니다.

## 2단계 — Firebase 연결 (구글 로그인·학생 데이터 실시간 동기화)

한 기기에서만 쓰려면 이 단계는 생략해도 됩니다(오프라인 모드로 동작). 여러 학생 기기에서 데이터를 모으려면 필요합니다.

1. https://console.firebase.google.com → **프로젝트 추가** (예: mandeok-art)
2. **인증(Authentication) → 시작하기 → Google → 사용 설정 → 저장**
3. 같은 화면 **Settings → 승인된 도메인**에 `내아이디.github.io` 추가
4. **Firestore Database → 만들기** (위치: asia-southeast1 권장, 프로덕션 모드) → 아래 규칙 붙여넣기:

```
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /classes/{code} {
      allow read, write: if true;
    }
  }
}
```

> ⚠ 이 앱은 학급 코드를 아는 사람만 접속할 수 있게 설계되어 있고, 개인정보 최소화 원칙에 따라 **실명 대신 닉네임**만 저장합니다. 학급 코드는 수업 시간에만 공개하세요.

5. **프로젝트 설정(⚙) → 일반 → 내 앱 → 웹앱 추가(</> 아이콘)** → 닉네임 아무거나 → 등록 → 표시되는 **firebaseConfig** 코드 전체 복사

6. 앱에서: 교사로 입장 → **설정 → Firebase 설정**에 config 붙여넣기 → **연결 테스트** → 저장

## 3단계 — AI 엔진 (만더기 AI 심화 모드, 선택)

- **기본 엔진은 내장되어 있습니다**(EXAONE 4.5 33B, 별도 설정 불필요 — 교실 데모용 프록시 연결).
- 더 강한 답변이 필요하면 Gemini로 전환 가능:
  1. https://aistudio.google.com → 구글 로그인 → **Get API key → Create API key** (무료)
  2. 앱 **설정 → Gemini API**에 키 붙여넣고 저장 → 설정에서 **AI 엔진: gemini** 선택
  3. 학생 챗봇에서 "AI 모드"가 켜집니다(키가 없으면 지식베이스 모드로만 동작)
- ⚠ AI 답변은 오류가 있을 수 있습니다 — 학생용 UI에도 "AI 답변은 확인이 필요해요" 안내가 항상 표시됩니다. 무료 티어 사용량 제한(분당 횟수)이 있으니 전교생 동시 사용은 권장하지 않습니다.

## 4단계 — 우리 반 아트 보드 (내장, 설정 불필요)

패들렛 유료 구독 없이도 작품 게시판이 앱 안에 들어 있습니다.

- 학생이 **성찰실에 작품을 등록하면 우리 반 보드에 자동 게시**됩니다(별도 버튼·키 불필요)
- **학생**: 성찰실 상단 **"우리 반 보드"** 버튼 → 반 친구 작품 보기 → 카드 클릭 → **코멘트 남기기**([12미03-03] 감상 소통)
- **교사**: 교사실 **"아트 보드" 탭** → 전체 작품 갤러리 + 상세·코멘트 확인
- 오프라인 모드: 이 기기에 저장된 성찰만 보이고, Firebase 연결(2단계) 후에는 반 전체가 실시간 공유됩니다
- 성찰카드 PNG 내려받기 버튼은 유지 — 출력·다른 곳 첨부용으로 그대로 쓸 수 있습니다

## 수업 운영 흐름

1. **교사**: 로그인 → 학급 만들기(이름 예: "2-3") → 학급 코드·QR 카드 발급(인쇄 버튼)
2. **학생**: QR 스캔 또는 링크 또는 코드 입력 → 학번 + 닉네임 등록 → 입장
3. 수업 중: 아이디어 공방(5단계) → 스케치 진단 → 퀴즈(형성평가 모드는 기록됨) → 작품 완성 후 성찰실 등록
4. **교사 대시보드**: 현황·퀴즈 영역별 오답 분석(어려워하는 부분 자동 표시) → 학생별 피드백 전송
5. **교과세특**: 교사 대시보드 → 교과세특 초안 → 학생 선택 → 생성 → 바이트 확인(1,500 이내) → 복사 → 나이스에 붙여넣기
   - ⚠ 초안은 **기록 기반의 참고용**입니다. 반드시 학생의 실제 수행을 확인하고 수정·보완하여 입력하세요.

## 자주 묻는 질문

- **오프라인(단일 파일)으로도 쓸 수 있나요?** 네. index.html을 그대로 열면 오프라인 모드로 동작합니다. 단, 데이터는 그 기기에만 저장되고 구글 로그인·실시간 동기화·AI 엔진은 인터넷+배포 버전에서만 동작합니다.
- **학생 수 제한?** Firestore 무료 티어 기준 한 학급(30~40명)은 충분히 무료 범위입니다.
- **사진 용량?** 학생 사진은 업로드 시 자동으로 최대 1000px·JPEG 압축(수백 KB)됩니다.
- **학급이 여러 개?** 학급 코드가 다르면 데이터가 완전히 분리됩니다. 반별로 각각 학급을 만들면 됩니다(사이트를 따로 만들 필요 없음).
- **퀴즈 추가/수정?** index.html 안의 `QUIZ=[...]` 배열에서 문항을 추가하면 됩니다(성취기준 코드만 맞춰 주세요).
